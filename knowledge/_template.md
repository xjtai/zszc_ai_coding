# 〔一句话标题：这条知识管什么〕

## 结论

〔一句话说死。不要铺垫，不要"视情况而定"。Agent 读完这一句就该知道怎么做。〕

## 边界

- **是**：〔明确包含什么〕
- **不是**：〔明确不包含什么——这行最值钱，词义漂移都是从这里开始的〕

## 最容易搞错的

〔一个具体反例：曾经有人/有 Agent 把它理解成什么，导致了什么后果。没有真实反例就写最可能的误解。〕

## 出处

- 负责人：〔谁能拍板，出了歧义找谁〕
- 依据：〔文档链接 / 代码路径 / 会议纪要，能追溯即可〕
- 更新：〔YYYY-MM-DD〕
